# Portofolio Dinamis - Tania

Website Portofolio / CV Dinamis untuk UTS Pemrograman Web.
Memiliki halaman publik untuk menampilkan profil dan halaman 
Dashboard untuk mengelola isi portofolio.

## Teknologi
- Backend: Python (Flask)
- Frontend: HTML, CSS, JavaScript
- Database: SQLite

## Fitur
- Halaman Publik (Profil, Skills, Pengalaman, Proyek)
- Login Admin
- Dashboard Admin
- CRUD Skills, Pengalaman, dan Proyek (Tambah, Lihat, Hapus)

## Cara Menjalankan Secara Lokal
1. Clone repository ini
2. Install Flask: pip install flask
3. Jalankan: python app.py
4. Buka di browser: http://127.0.0.1:5000
5. Login untuk masuk ke Dashboard dan mengelola data
